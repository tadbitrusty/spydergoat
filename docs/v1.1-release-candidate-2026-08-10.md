## Candidate

SpyderGoat v1.1 adds a Vite, React 19, and TypeScript frontend to the existing Cloudflare Worker deployment. The Worker remains authoritative for API routing, paid-route gates, security headers, and a fresh server-time bootstrap. Vite assets are deployed through the Worker Static Assets binding.

The navy/amber interface includes the MJD instrument panel, epoch ruler, Why MJD, use cases, runtime facts, full public API example, and truthful free/paused access states. It includes a useful no-JavaScript fallback and a truthful browser-preview state for the Vite development server.

## Preserved boundaries

- `/mjd` and `/jd` remain public.
- KV is a best-effort free-tier limiter, not transactional accounting.
- Paid bearer-key access remains fail-closed.
- `/success` remains a 503 paid-access-paused notice with no key disclosure.
- `/webhook` remains 503 until transactional billing is configured.
- No checkout or top-up links are packaged.
- No production D1 migration was applied.
- The four known Stripe Payment Links were manually deactivated by Adam and independently verified inactive before this candidate was built.
